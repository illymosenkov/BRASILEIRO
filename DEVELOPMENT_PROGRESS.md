## Контрольная точка 7 — миграция и полная резервная копия
Новая схема v5 и отдельный ключ bora_civic_v5. Исходное хранилище 4.3 оставлено для восстановления. ### Ограничения
- Точный локальный прогресс пользователя доступен на его устройстве. Проверки использовали данные настоящих упражнений на тестовой установке. Сведения, которых 4.3 не записывала, отсутствуют и после миграции.
- При ручном переводе принимаются предусмотренные варианты, регистр, пробелы и ввод без диакритики. Свободный перевод может требовать другой естественной формулировки. A1–B2 задают сложность упражнений, без отдельного экзамена на уровень.
- Автоматические повторы в рамках одной короткой тренировки ограничены. Когда нет других заданий для перемежения, слово остаётся в очереди последующих повторений.
- Учебные данные хранятся на телефоне. Нужна резервная копия перед удалением приложения или переносом на другое устройство. Экспорт Android поддерживает файлы до 16 МиБ; раньше может исчерпаться лимит localStorage WebView.
- Для будущего официального обновления нужна та же закрытая подпись. Ключ не опубликован в Git и не включён в ZIP.
